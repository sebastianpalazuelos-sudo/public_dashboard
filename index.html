Filosofía y Descubrimientos

El objetivo inicial del sistema fue construir una herramienta capaz de valorar con la mayor precisión posible la performance de un jugador en cada partida. Durante su desarrollo se probaron distintas fórmulas, ponderaciones y métodos de normalización, buscando una forma consistente de transformar las métricas disponibles en una valoración del rendimiento.

En la mayoría de los casos, los distintos modelos producían resultados similares a las valoraciones observadas de Riot. Sin embargo, también aparecían excepciones puntuales que resultaban difíciles de justificar o que generaban resultados controvertidos. Al analizar múltiples partidas, surgió además un patrón más estable: a medida que se acumulaban observaciones, las posiciones relativas de los jugadores tendían a conservar cierta consistencia al analizarlos desde diferentes perspectivas.

El desarrollo permitió identificar dos límites fundamentales: la capacidad del modelador para representar correctamente el rendimiento y la ausencia de datos relevantes en la información disponible del cliente. Esto marcó una diferencia importante entre lo que el sistema podía calcular y lo que realmente podía demostrar.

La conclusión fue simplificar el problema. En lugar de intentar construir una fórmula capaz de resolver aspectos que requieren información que los datos disponibles no contienen, el sistema se concentra en medir de forma transparente y reproducible aquello que puede observarse.

El modelo actual resume el rendimiento de cada partida a partir de seis dimensiones observables: KPM, DPM, CCPM, Tank Share, KDA y Gold SPM. Estas dimensiones permiten representar distintas formas de contribución del jugador y reducir la dependencia de una única métrica.

Cada dimensión se transforma en una puntuación común de 0 a 10 y las seis puntuaciones se integran en un Score Global de la partida. Este resultado permite describir el rendimiento observable de un jugador, pero no elimina una limitación fundamental: los campeones no tienen las mismas posibilidades de producir rendimiento en cada dimensión.

Por esta razón, el sistema construye también una referencia histórica para cada campeón. Esta referencia permite interpretar el resultado de una partida dentro del contexto estadístico propio del campeón utilizado, en lugar de comparar directamente valores que pueden tener comportamientos naturales diferentes.

El primer intento para realizar esta comparación fue el Meta Ratio, que relacionaba el Score de una partida con el rendimiento histórico de su campeón. Sin embargo, se detectó que esta relación podía estar sesgada por las diferencias de escala entre campeones.

La solución fue utilizar una referencia basada en la propia distribución histórica de cada campeón: el percentil 95 (P95). Un percentil expresa la posición relativa de un valor dentro de una distribución: de forma intuitiva, los percentiles bajos representan resultados poco destacados y los percentiles altos resultados cada vez más excepcionales. El P95 identifica un nivel de rendimiento que se encuentra por encima de aproximadamente el 95% de las observaciones históricas del campeón.

A partir de esta referencia se construyó el P95R, cuyo objetivo es expresar el rendimiento de una partida en relación con ese nivel excepcional histórico, manteniendo el contexto propio de cada campeón.
